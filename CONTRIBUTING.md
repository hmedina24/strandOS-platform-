# Contributing to StrandOS

## Branches

Use short, descriptive branches such as `feature/booking-calendar` or `fix/payment-deposit-validation`.

## Pull requests

- Keep changes focused on one concern.
- Add or update tests when application behavior changes.
- Do not commit secrets, production data, client photos, or real customer information.
- Document material architecture decisions in `docs/decisions/`.

## Security

Report security concerns privately to the project owner. Do not include credentials or sensitive client data in issues, commits, or pull requests.
